# RegSense Landing (free static)

This is a minimal “Coming soon + join waitlist” landing page.

## Customize

1) In `index.html`, replace:
- `WAITLIST_URL` with your Google Form / Typeform URL
- `hello@regsense.example` with your email (optional)

## Deploy free

### GitHub Pages

1) Create a GitHub repo (e.g. `regsense-landing`)
2) Commit these files to the repo root
3) GitHub → Settings → Pages → Deploy from branch → `main` / `/ (root)`

### Cloudflare Pages

1) Create repo
2) Cloudflare Pages → connect repo → deploy

No build step required.
